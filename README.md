The Daily Ledger — Monday, 23 November 2026: the world's news summed up in one 1024×1024 front-page image. Forty stories, from the collapse of COP31 in Antalya and the Democrats' largest House majority since 1992 to the Dymer strike, the Asia AI sell-off and Alcaraz's first ATP Finals crown, set as a classic newspaper front page with a markets strip and the day in numbers. The program at main.ts copies the page (entry.png) to the output directory; stories.json holds the day's stories, build_page.mjs sets the page, and render.mjs screenshots it at exactly 1024×1024.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
